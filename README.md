# FOREST RUNNER – 2D Endless Runner (Unity 6)

## How to run (beginner steps)
1. Install **Unity Hub** and **Unity 6.3 LTS (6000.3.x)** (Hub: Installs > Install Editor). Any Unity 6 version works.
2. Extract the ZIP.
3. Unity Hub > **Add > Add project from disk** > select the `ForestRunner` folder.
4. Open it. First open takes a few minutes (packages import). If Hub asks to change editor version, choose your installed Unity 6.
5. If Unity asks about enabling the **new Input System backend** – click **Yes** (editor restarts) or **No**. Both work.
6. Wait a few seconds: the project creates `MainMenu` and `GameScene` and opens the menu automatically.
7. Press **Play**. (Play always starts from the Main Menu.)

If anything seems missing, use menu **Forest Runner > Setup Project**.
Tip: in the Game tab pick any size; the game keeps a 9:16 portrait frame by itself.

## Controls
| Action | Keyboard | Touch / mouse drag |
|---|---|---|
| Move left / right | A D / Arrow keys | Swipe left / right |
| Jump | W / Up / Space | Swipe up |
| Slide | S / Down | Swipe down |
| Pause | Esc / P | Pause button |

## Gameplay
Three lanes. Tree trunks = change lane. Stumps, rocks, thorns, wild boars = jump. Fallen trees and flying owls = slide.
Coins (+10), fruit (+100), leaves (+25). Power-ups: Magnet, Shield, Speed Boost, Score x2.
Theme changes every 600 m: Enchanted Forest > Bamboo Grove > Magic Woodland > Tree Village.
Revive costs 50 coins, once per run. You start with 100 coins. Best score and coins are saved (PlayerPrefs).

## How it works
All art and sound are generated by code (no image/audio files, so nothing can be "missing").
`SceneRoot` builds each scene at start-up. Scripts are in `Assets/Scripts`, scene generator in `Assets/Editor`.
